# AuditPilot roadmap

This is an early-access toolkit. Items below are directions, not delivery promises.

## Implemented

- CSV / XLSX register validation with 14 rules.
- Local browser demo, synthetic samples, filters and findings export.
- Evidence parsing, classification, metadata and deterministic quality checks.
- A.5.1 / A.5.2 starter control mapping, coverage, gap and action suggestions.
- Locked Python dependencies, automated tests and CI configuration.

## Next: reliable review workflows

- Evaluate header normalization and spreadsheet edge cases with practitioners.
- Separate evidence-quality review from keyword-based coverage.
- Add ownership, due dates, lifecycle and closure evidence to actions.
- Persist evidence and actions with migrations and clear data handling.
- Extend the control library through reviewed, properly scoped contributions.

## Later

- Broader reporting and dashboard workflows.
- Authentication and authorization for shared deployments.
- GitHub Issues / Jira / Azure DevOps integrations where users need them.
- AI-assisted evidence review and search with explicit human review.
- Additional frameworks after the initial workflows are validated.

Keep future capabilities out of claims about the current release.
